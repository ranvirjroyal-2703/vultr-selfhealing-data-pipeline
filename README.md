# Self-Healing Health Data Pipeline Agent

**Code for a Billion — Bharat Agentic-AI Hackathon 2026**  
**Track: Health**

A self-healing agent that cleans messy public-health and clinical data exports. Every cleaning strategy is generated by an LLM, executed inside a locked-down Docker sandbox, automatically repaired from real errors, and ranked by cost (time × memory). The same sandbox is proven to contain runaway code (infinite loops, resource bombs).

## Problem

Health systems, NGOs, and district hospitals regularly receive messy CSV exports from field apps, labs, and surveys. Columns are misnamed, amounts are strings, duplicates exist, and empty rows break pipelines. Manual cleaning is slow and error-prone. An agent that can propose, test, repair, and select the cheapest safe clean reduces the time from “raw export” to “analysis-ready dataset” from hours to minutes while guaranteeing the host system stays safe.

## What the demo shows

1. A planted bad strategy fails with a real `KeyError`.
2. The LLM rewrites the code from the stderr. The repaired version runs successfully in a fresh sandbox.
3. Surviving strategies are ranked by cost. The cheapest successful clean is recommended.
4. An infinite loop is killed by the sandbox while the app stays up (blast-radius zero).

One button does all four: **Run judge demo**.

## Run locally

```bash
pip install -r requirements.txt
docker build -t data-pipeline-sandbox -f sandbox/Dockerfile sandbox
export VULTR_INFERENCE_API_KEY=your_key   # or any OpenAI-compatible endpoint
streamlit run app.py
```

## Architecture

- **Streamlit UI** — uploads or uses the sample messy CSV, shows failure + repair side-by-side, cost table, and containment proof.
- **Agent** — proposes cleaning strategies, executes them in the sandbox, heals failed code from stderr, ranks by cost.
- **Sandbox runner** — Docker with no network, non-root user, memory/CPU/pids limits, timeout, ephemeral containers.
- **LLM** — strategy generation + code repair (originally Vultr Inference; any OpenAI-compatible API works).

## Deploy

Any cloud that can run Docker + Streamlit works (Streamlit Cloud, Render, Railway, Vultr, etc.). See `deploy.sh` for a simple VM script.
